摘要

本研究使用 Kaggle Flood Prediction Dataset 版本 1 的 50,000 筆資料與 20 個數值特徵，依 CRISP-DM 建立可重現的多元線性迴歸流程。資料以固定亂數種子切為 40,000 筆訓練與 10,000 筆測試，前處理和特徵選擇均在交叉驗證訓練折內完成。完整 OLS 的測試 R² 為 1；事後以十進位精確運算核對發現，全部目標都等於 20 個輸入分數加總除以 200。研究價值在於揭露資料的確定性規則、解釋刪除特徵的誤差，以及避免將完美擬合誤認為真實災害預測能力。

1. Business Understanding｜商業理解

情境：若取得環境與社會因素評分，能否預測 FloodProbability？能否用較少欄位維持表現？主要比較標準為訓練集五折 CV RMSE，測試集用於最終評估。將預測訓練平均值設為最低基準，並比較解釋性較高的線性模型與非線性樹模型。資料沒有真實時空識別、感測器量測或事件標籤證據，因此成果定位為分析教學，不作預警、保險定價或因果政策建議。

3. Data Preparation｜資料準備

先移除完全重複列與缺少目標列，再使用 train_test_split(test_size=0.2, random_state=711405612)。訓練資料內以 KFold(5, shuffle=True, random_state=711405612) 建立共用折。每折的 SimpleImputer(median)、StandardScaler、特徵選擇與模型都置於 Pipeline；不以驗證或測試資料擬合。資料沒有類別欄，因此不需要 one-hot encoding。未刪除極端值，以免任意改變分布。原始 CSV 列號及每折驗證位置保存在 reports/splits.json。

4. Modeling｜建模與特徵選擇

完整 OLS 含截距，最小化殘差平方和。Ridge 使用 L2 懲罰，alpha = 0.01、1、100、1000；Lasso 使用 L1 懲罰，alpha = 10^-6、10^-5、10^-4、10^-3、10^-2，max_iter=20000、tol=10^-9。StandardScaler 只標準化 X，未標準化 y；兩種模型的 alpha 定義不同，不直接比較其數字大小。

SelectKBest 用訓練折內的單變量 f_regression 分數選欄；RFE 以標準化後的線性係數遞迴剔除，每次移除 1 欄。兩者均測試 k=5、10、14、16、18、20，之後擬合 OLS。額外的 Histogram Gradient Boosting 設 max_iter=200、max_leaf_nodes=15 或 31、early_stopping=True，只在訓練折內早停。七個方法共用相同五折；GridSearchCV 依平均 CV RMSE 選參數。

預測模型在讀取測試成績前依 CV 鎖定。完整 OLS 與選滿 20 欄的選擇器本質上是同一模型；近乎零的誤差差異只反映浮點運算，不宣稱存在實質優劣。CV 參與調參，最佳 CV 分數仍有選擇偏差；測試資料才是留出評估。

5. Evaluation｜評估與結果解釋

重要發現：訓練完成後，使用 Python Decimal 以 CSV 原始十進位字串逐筆核對：FloodProbability = (MonsoonIntensity + … + PoliticalFactors) / 200。50,000 / 50,000 筆完全相等，最大十進位誤差為 0。此稽核沒有用來訓練或調參，只用於解釋異常高分。這支持「所提供資料存在確定性目標公式」，但不能單憑公式斷言作者如何收集或生成資料。

因此每個輸入分數的原始尺度 OLS 係數約為 0.005，截距約為 0。完整模型重建公式，R²=1 與近零 RMSE 是合理數值結果；刪掉任何有變動的因素就失去公式資訊，故兩種選擇器都選滿 20 欄。沒有為了展示「特徵選擇成功」而強制保留較少欄位。

五項假設診斷

線性：逐筆精確公式及圖形支持本表內的線性關係。共線性：完整 OLS 最大 VIF = 1.000767，沒有顯著共線性跡象。獨立性：缺乏時間、地點或群組資訊，無法確認，不能用打亂順序後的 Durbin–Watson 宣稱通過。

等變異與殘差常態：完整模型殘差只剩浮點運算誤差；RESET、Breusch–Pagan、Jarque–Bera 與 Durbin–Watson 的數值無法作為有意義的統計證據，結果欄設為不適用。原始計算值只保存在 numerical_only_do_not_interpret 供稽核。一般 OLS 預測區間會退化為近乎零寬，故網站與報告不提供誤導性的 95% 區間；題目要求的預測圖已完整提供。

20 個分數總和除以 200 等於算術平均值再除以 10，不能直接稱為原始分數的算術平均值。

觀察到確定性公式不足以證明作者使用人工或合成資料；保留資料生成與蒐集背景未獲獨立驗證的表述。

等權重不等於每欄固定貢獻 1/20 資訊；資訊損失取決於變異與欄位間依賴。本資料的特徵刪減結果由交叉驗證支持。
